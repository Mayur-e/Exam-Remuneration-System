This README lists, for **Computer Engineering department students only**:

- **Year** (SY / TY / BTech)
- **Subject Code**
- **Subject Name**
- **Course Type** (as per curriculum abbreviations – PCC, PEC, MDM, OEC, VSEC, HSSM, AEC, VEC, ELC, HN, INTR, PROJ, etc.)
- **Registered Count** (from registration sheet)

---

## Abbreviations Used (Course Type)

- **PCC** – Programme Core Course  
- **PEC** – Programme Elective Course  
- **MDM** – Multidisciplinary Minor  
- **OEC / OE** – Open Elective Course  
- **VSEC / VS** – Vocational & Skill Enhancement Course  
- **ELC / EL** – Experiential Learning Course  
- **HSSM / EEM** – Entrepreneurship / Economics / Management / Humanities & Social Sciences  
- **AEC** – Ability Enhancement Course  
- **VEC / VE** – Value Education Course  
- **HSMC** – Humanities, Social Sciences and Management Course (Reg. 2020)  
- **PFC** – Proficiency Course (Reg. 2020)  
- **AC** – Audit Course (Reg. 2020)  
- **LS** – Life Skill (Reg. 2020, used for skill / seminar style courses)  
- **HN** – Honors Course  
- **INTR** – Internship  
- **PROJ** – Project / Project Based Learning
