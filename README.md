# 🎓 Exam Remuneration System

A comprehensive, automated web application for managing exam remuneration claims in educational institutions. This system streamlines the entire workflow from claim submission to final payment, ensuring accuracy, transparency, and efficiency.

## 🚀 Overview

The **Exam Remuneration System** digitizes the manual process of claiming remuneration for exam duties. It supports:
- **Teaching Staff (Internal & External):** Paper setting, evaluation, oral/practical exams, moderation.
- **Non-Teaching Staff:** Laboratory assistance, cleaning, peon duties, administrative support.

---

## 🏛️ Functionality by Panel

### 👨‍🏫 Faculty Panel (Internal)
Designed for internal staff to manage their exam duties and claims efficiently.

- **Dashboard**:
  - **Real-time Status**: View counts of Draft, Pending, Approved, Rejected, and Paid claims.
  - **Recent Activity**: Quick access to recently modified claims.
  - **Quick Actions**: One-click buttons to start new teaching or non-teaching claims.
- **Claim Generation**:
  - **Teaching Claims**:
    - **Internal**: For duties like invigilation, paper assessment, and moderation.
    - **External**: For duties performed by external examiners (includes generating secure links).
  - **Non-Teaching Claims**:
    - **Expert Assistant**: Automatically assigns the logged-in faculty as the Expert Assistant.
    - **Staff Allocation**: Add support staff (Lab Assistant, Peon) with auto-calculation of days and rates.
    - **Date Sync**: Exam dates are automatically synchronized for accurate billing.
  - **Drafts**: Claims are auto-saved as drafts, allowing faculty to pause and resume work anytime.
- **My Claims**:
  - **Filter & Search**: Sort claims by status, subject, or date.
  - **Detailed View**: View full breakdown of remuneration (Paper Setting + Assessment + Moderation + Allowances).
  - **Edit/Resubmit**: Modify draft claims or resubmit rejected claims with corrections.
- **Profile & Settings**:
  - **Bank Details**: Securely manage bank account information (Account No, IFSC, Bank Name) for payouts.
  - **Personal Info**: Update contact details and department.

### 🔗 External Examiner Panel (Guest Access)
A secure, simplified interface for external examiners who do not have a system account.

- **Secure Access**: Access via a unique, time-limited link generated by the internal faculty.
- **Claim Submission**:
  - **Duty Details**: View assigned duties (Paper Setting, Oral/Practical).
  - **Document Upload**: Mandatory upload of **PAN Card**, **Cancelled Cheque**, and **Travel Tickets** (if applicable).
  - **Bank Details**: Enter bank information for direct remuneration transfer.
- **Status Tracking**: Receive email notifications on claim approval or payment.

### 🛡️ Admin Panel
The central control hub for managing the entire remuneration process.

- **Dashboard**:
  - **System Overview**: High-level metrics on Total Claims, Amount Disbursed, and Pending Approvals.
  - **Visual Analytics**: Interactive charts showing claim distribution by department and status.
- **Claim Management**:
  - **Verification Queue**: Review pending claims with a detailed breakdown of calculations.
  - **Approve/Reject**:
    - **One-Click Approval**: For standard claims meeting all criteria.
    - **Rejection with Feedback**: Reject claims with specific comments, visible to the faculty for correction.
    - **Send Back**: Return claims for minor corrections without full rejection.
- **User Management**: Manage faculty accounts, roles, and permissions.
- **Reports & Exports**:
  - **Excel Export**: Generate detailed billing sheets compatible with bank formats.
  - **PDF Generation**: Download official remuneration slips for record-keeping.

### 💰 Accounts Panel
Focused on final verification and payment processing.

- **Payment Processing**:
  - **Final Verification**: Double-check amounts approved by Admin.
  - **Batch Processing**: Mark multiple claims as "Paid" simultaneously after bank transfer.
- **Financial Reports**:
  - **Ledger View**: View detailed history of all payments made.
  - **Tax & TDS**: Automatic calculation and reporting of TDS deductions where applicable.

## 🛠️ Technology Stack

- **Frontend**: React.js (Vite), Tailwind CSS, Framer Motion, Lucide React
- **Backend**: Node.js, Express.js, PostgreSQL (pg)
- **Authentication**: JWT (JSON Web Tokens), Google OAuth
- **Tools**: ExcelJS (Reports), PDFMake (Slips)

## ⚙️ Installation & Setup

### Prerequisites
- Node.js (v18+)
- PostgreSQL (v14+)
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/Mayur-e/Exam-Remuneration-System.git
cd Exam-Remuneration-System
```

### 2. Database Setup
1. Create a PostgreSQL database (e.g., `exam_remuneration`).
2. Run SQL scripts in `database/` to create tables:
   ```bash
   psql -U postgres -d exam_remuneration -f database/schema.sql
   ```

### 3. Backend Setup
1. `cd backend`
2. `npm install`
3. Create `.env`:
   ```env
   PORT=5000
   DB_USER=postgres
   DB_HOST=localhost
   DB_NAME=exam_remuneration
   DB_PASSWORD=your_password
   DB_PORT=5432
   JWT_SECRET=your_jwt_secret
   FRONTEND_URL=http://localhost:5173
   ```
4. `npm run dev`

### 4. Frontend Setup
1. `cd frontend`
2. `npm install`
3. Create `.env`:
   ```env
   VITE_API_URL=http://localhost:5000/api
   ```
4. `npm run dev`
